# Скрипты автоматизации развертывания и удаления виртуальных машин УТК-СЗИ

Скрипт install.sh выполняет следующие действия:
1. Проверяет наличие и в случае отсутствия создает виртуальные сети `intnet` и `extnet`;
2. Создает новый пул (по умолчанию с именем текущего пользователя);
3. Копирует из текущего каталога все имеющиеся образы виртуальных дисков в созданный пул и регистрирует их;
4. Создает виртуальные машины по всем xml-описаниям в текущем каталоге.

Запуск скрипта выполнять из терминала, запущенного в сеансе обучаемого(инструктора), т.к. пул создается в домашнем каталоге пользователя, запустившего скрипт.

Для создания пустых образов нужной емкости использовать команды:
qemu-img create -f qcow2 arm-abi.qcow2 16G
qemu-img create -f qcow2 srv-szi.qcow2 32G
