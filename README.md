# Скрипты автоматизации развертывания и удаления виртуальных машин УТК-СЗИ

Скрипт vmlab.sh выполняет следующие действия:
1. Проверяет наличие и в случае отсутствия создает виртуальные сети `intnet` и `extnet`;
2. Создает iso-образ с файлами из подкаталога distros в каталоге images;
3. Копирует все iso- и qcow2-образы из каталога images в системный пул;
4. Создает в текущем каталоге оверлейные образы из базовых qcow2-образов в каталоге images;
5. Создает новый пул с именем пользователя, указанного в параметре --user;
6. Копирует из текущего каталога все qcow2-образы дисков в созданный пул и регистрирует их;
7. Создает виртуальные машины по всем xml-описаниям, имеющимся в текущем каталоге.

Запуск скрипта выполнять из терминала, запущенного в сеансе обучаемого(инструктора), т.к. пул создается в домашнем каталоге пользователя, запустившего скрипт.

Для создания пустых образов нужной емкости использовать команды:
```
qemu-img create -f qcow2 arm-abi.qcow2 16G
qemu-img create -f qcow2 srv-szi.qcow2 32G
```
